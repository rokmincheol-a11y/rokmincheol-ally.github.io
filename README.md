# M's Workspace

민철의 개인 작업실 · 합동 비서실 — 브라우저에서 바로 쓰는 정적 대시보드.

## 구성

| 기능 | 설명 |
| --- | --- |
| 오늘의 할 일 | 추가 · 완료 체크 · 삭제, 진행률 표시 |
| 합동 비서실 보드 | 담당(나 / 뽕구 / 다른 피클)과 상태(대기 / 진행 중 / 완료)를 카드로 관리, 드래그로 상태 이동 |
| 자유 메모 | 아이디어 · 공부 노트를 카드로 저장, 내용은 바로 수정 가능 |
| 바로가기 | Notion, Google Calendar, GitHub 등 자주 쓰는 도구 링크(직접 추가 · 삭제) |
| 데이터 | JSON 내보내기 / 가져오기, 전체 초기화 |
| 테마 | 라이트 / 다크 모드 토글 |

## 기술

- 빌드 도구 없이 순수 HTML · CSS · JavaScript
- 모든 데이터는 브라우저 `localStorage`에만 저장되며 서버로 전송되지 않습니다.
- GitHub Pages로 그대로 배포할 수 있습니다.

## 파일

```
index.html    화면 구조
styles.css    디자인 (라이트/다크, 반응형)
app.js        상태 관리 · 저장 · 내보내기/가져오기
```

## 로컬에서 보기

```bash
python3 -m http.server 8000
# http://localhost:8000
```
